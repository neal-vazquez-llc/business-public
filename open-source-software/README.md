# Open-Source Software

Open-source software developed and released by **Neal Vazquez LLC**, with **Neal Vazquez** as developer.

This area is the GitHub home for the company's intentionally published software. The first project is [TabShotter](tabshotter/), a user-controlled browser snapshot tool being prepared for desktop use.

## Distribution boundary

The intended release channels are:

- the official project pages and downloads on [neal-vazquez.com](https://neal-vazquez.com/corporate/open-source-software);
- this GitHub repository.

No third-party model hub, extension store, package registry, mirror, or community distribution is part of the release plan.

## Release status

TabShotter is in release preparation under the MIT License. The source, installers, checksums, and download links will be added only after rights confirmation, browser-security validation, clean-machine installer testing, and final package review. Until then, this directory is a public-facing project index, not a downloadable release.
