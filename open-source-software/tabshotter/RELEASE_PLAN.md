# TabShotter release plan

This is a planning record, not a release approval.

1. Confirm the exact source and derivative-release rights.
2. Confirm the staged MIT License is the approved license for this source package.
3. Complete unit, syntax, and real-browser security validation.
4. Complete manual unpacked-extension and desktop-shell checks.
5. Build and test Windows, macOS, and Linux installers on clean machines.
6. Review the final package for private captures, identities, credentials, browser profiles, and unrelated files.
7. Generate and verify checksums and release notes.
8. Add website download links only after the matching GitHub artifacts are read back.

The project remains unreleased until every applicable gate has evidence.
