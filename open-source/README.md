# Open Source

Open-source software developed and released by **Neal Vazquez LLC**, with **Neal Vazquez** as developer.

This area is the GitHub home for the company's intentionally published software. The first project is [TabShotter](tabshotter/), a user-controlled Chromium browser snapshot extension.

## Distribution boundary

The intended release channels are:

- the official project pages and downloads on [neal-vazquez.com](https://neal-vazquez.com/corporate/open-source);
- this GitHub repository.

No third-party model hub, extension store, package registry, mirror, or community distribution is part of the release plan.

## Release status

TabShotter v0.1.0 is available as a limited Chromium package. Firefox support and Windows, macOS, and Linux installers are not claimed.
