# Business Public

Public business repository for intentionally published open-source software and the SQL/Python showcase.

## Start here

This repository is one of four canonical roots:

- Personal Private
- Personal Public
- Business Private
- Business Public

Canonical routing is constant-depth:

`scope -> visibility -> area -> project -> artifact`

The repository boundary already supplies `scope=business` and `visibility=public`, so content inside this repository is organized as:

`area/project/artifact`

## Areas

- `open-source`
- `python-sql-showcase`

## Migration status

This repository is the public release surface for software and technical showcase material only.

Legacy repositories remain available during import and verification. No old repository, branch, tag, license, evidence record, or deployment reference is retired merely because this root now exists.

## Naming

- machine IDs and GitHub paths: lowercase kebab-case
- human display names: readable title case
- dates when materially identifying an artifact: `YYYYMMDD - Title.ext`
- preserve project-internal code/import/build/deployment paths when renaming would create breakage
- preserve historical/evidence names when renaming would distort provenance

## Publication boundary

Everything committed here must already be intentionally public. Private source history, private case evidence, credentials, account data, and private correspondence never migrate here merely because a related public project exists.
